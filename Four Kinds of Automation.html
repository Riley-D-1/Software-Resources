Four Kinds of Automation

Four ways to make computers do the boring jobs

Imagine a cake shop. Each idea below is a different helper that keeps the shop running.

DevOpsRPABPAMLOps

DevOps

Development + Operations

The bakers and the shop staff become one team that never stops looping.

  • Coders (Dev) and the people who run the servers (Ops) work together.
  • Robots build, test and ship new code automatically (CI/CD).
  • Small changes, shipped often, watched closely.

Example: you push a fix to GitHub, tests run by themselves, and the app updates within minutes.

RPA

Robotic Process Automation

A software robot that uses the computer exactly like a person would.

  • It clicks, types, copies and pastes on the screen.
  • Great for boring, repeated jobs with clear rules.
  • Copies a human's steps. It does not redesign the job.

Example: every morning a bot opens 50 order emails and types each total into the sales spreadsheet.

BPA

Business Process Automation

Redesign the whole job so the systems pass work to each other by themselves.

  • Covers a full process from start to end, not one screen.
  • Apps talk directly through APIs and workflows.
  • People only step in for decisions and problems.

Example: a cake order on the website checks stock, charges the card, books the van and emails a receipt. Nobody touches it.

MLOps

Machine Learning Operations

DevOps for a robot brain. The brain needs fresh lessons or it slowly gets worse.

  • Looks after the data, the training and the model, not just code.
  • Watches if predictions start going wrong (model drift).
  • Retrains and re-releases the model automatically.

Example: a model predicts how many cakes sell each day. Winter arrives, guesses drift, so it retrains on new sales data.

Spot the difference

DevOpsautomatesmaking and shipping software
RPAautomatesa person's clicks and typing
BPAautomatesa whole business process
MLOpsautomatesbuilding and caring for ML models

One-line memory trick: RPA copies the human. BPA redesigns the job. DevOps ships the code. MLOps keeps the AI brain fresh. Add machine learning to RPA or BPA and the bots can handle messy stuff too, like reading handwritten forms or deciding which emails are urgent.
