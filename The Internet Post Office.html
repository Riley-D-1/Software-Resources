Layer 7 · Application

Say It

Jamie types: "Hi Alex, want to play?"

Layer 6 · Presentation

Turn It into Code

A helper turns the words into a code every computer understands.

Layer 5 · Session

Hold the Line

A helper keeps the chat open, so Jamie and Alex can keep talking.

Layer 4 · Transport

Cut & Number It

A helper slices the message into little numbered pieces, so none get lost.

Layer 3 · Network

Add Alex's Town

A helper writes Alex's address, so every piece knows which way to go.

Layer 2 · Data Link

Tag the Next Stop

A helper tags each piece with directions to the very next delivery truck.

Layer 1 · Physical

Zoom Along the Wire

The pieces become tiny signals, zipping through a wire, Wi-Fi, or light.
