Five Kinds of Data Bias

Why computers learn the wrong lesson

A computer learns from a big pile of examples. If the pile is wonky, the computer learns wonky.

1 · Human bias

The teacher's own opinion sneaks in

A person labels the examples, and their likes and dislikes go into the labels.

So the computer thinks“Green apples are bad apples.”

Fix: have lots of different people label, and check each other's work.

2 · Dataset source bias

Every example came from the same place

One website, one school, one country. That place is not the whole world.

So the computer thinks“Cats are orange. A black cat is not a cat.”

Fix: collect examples from many different places.

3 · Sampling bias

You only asked some people

The people you picked are not like everybody else.

So the computer thinks“Everyone's favourite food is ice cream.”

Fix: pick people fairly, by chance, from everywhere.

4 · Historical bias

Old examples copy old unfairness

The data is true about the past, but the past wasn't fair. The computer copies it.

So the computer thinks“Doctors are men.”

Fix: spot the old pattern and choose not to copy it.

5 · Measurement bias

The measuring tool is off

If the ruler, sensor or survey is wonky, every number it gives is a bit wrong.

So the computer thinks“It's 45°C. Wear shorts!”

Fix: check your tools, and measure everything the same way.
