The Cake Life Cycle
Software Engineering 11–12 · Software development steps

Making software is like making a birthday cake

Eight steps, in order. Then you keep going round.

1

Requirements definition

Ask: what do you want?

In software: find out what the user needs.

2

Determining specifications

Write the exact list: chocolate, 3 layers, feeds 10.

In software: precise rules the program must meet.

3

Design

Draw the plan before you bake.

In software: algorithms, flowcharts, screen sketches.

4

Development

Bake each part.

In software: write the code, piece by piece.

5

Integration

Stack the parts into one cake.

In software: join modules so they work together.

6

Testing and debugging

Taste it. Find what's wrong. Fix it.

In software: run tests, hunt bugs, fix them.

7

Installation

Bring it to the party.

In software: put it on users' computers.

8

Maintenance

Fix cracks. Add a new candle.

In software: fix bugs, add features, update.

It's a loop

After step 8, people ask for new things. So you start again at step 1.

Two ways to go round

Waterfall

Do each step once, top to bottom. Like water down stairs. Hard to go back up.

Agile

Make a small cake fast, get feedback, make it better. Lots of little loops.

WAgile

A mix. Plan like Waterfall, build in Agile loops.

Step names come from the NESA Software Engineering 11–12 syllabus (2022): Programming Fundamentals and Secure Software Architecture. Waterfall, Agile and WAgile come from the Software Engineering Project.
