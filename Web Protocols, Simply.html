Web Protocols, Simply
Explain it like I'm five

How computers talk on the web

A protocol is just an agreed set of manners. Both sides follow the same rules, so the message makes sense when it arrives.

They stack like blocks

Each block does one small job and trusts the block under it.

Bottom: get it to the right house.
Middle: make sure nothing is lost, and lock it.
Top: what the message actually says.

What happens when you type cats.com

One trip, four steps

  1. 1
    DNS"Where does cats.com live?" Gets a number back.
  2. 2
    TCP"Hello?" "Hello!" "Ready." A line is open.
  3. 3
    TLSBoth sides agree on a secret lock.
  4. 4
    HTTP"Page, please." "Here you go!"
Group 1

Finding and delivering

IP

Internet Protocol

Every computer gets a house number. IP writes it on the envelope.

Like: the address on a letter.

DNS

Domain Name System

You remember names. Computers need numbers. DNS looks the name up.

Like: a phone book for websites.

TCP

Transmission Control Protocol

Cuts a message into numbered pieces. Checks every piece arrived, in order.

Like: a careful courier who wants a signature.

UDP

User Datagram Protocol

Throws pieces fast and never checks. Losing one is fine if speed matters more.

Like: live games and video calls.

Group 2

Talking to websites

HTTP

HyperText Transfer Protocol

You ask for a page. The server answers with a code and the page.

Like: ordering from a waiter. 200 = "here it is", 404 = "we don't have that".

HTTPS / TLS

HTTP + Transport Layer Security

Same as HTTP, but every message goes in a locked box only the two of you can open.

Like: the padlock in your browser bar.

WebSocket

two-way open line

HTTP hangs up after each answer. A WebSocket stays on the line so both sides can talk any time.

Like: chat apps and live scores.

HTTP/3 & QUIC

the newer, faster HTTP

Runs on UDP with its own checking. One slow piece no longer holds up all the others.

Like: a road with many lanes instead of one.

Group 3

Other jobs

SMTP & IMAP

email

SMTP posts your email. IMAP lets your phone and laptop read the same mailbox.

Like: dropping a letter in, then checking your box.

FTP / SFTP

File Transfer Protocol

Moves whole files between computers. SFTP is the locked, safe version.

Like: a moving truck for files.

SSH

Secure Shell

Type commands on a computer far away, safely, with a secret key.

Like: a locked remote control.

WebRTC

Web Real-Time Communication

A server helps two browsers find each other. Then they talk straight to each other.

Like: video calls in the browser.

The one sentence to remember: IP finds the house, TCP makes sure nothing gets lost, TLS locks it, HTTP is what you say.
